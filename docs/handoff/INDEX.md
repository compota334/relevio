# Handoff library index

This file is GENERATED by relevio (`relevio-index.sh`): never edit it by hand.
It is rebuilt from the metadata header of every handoff found on ANY branch
(`git log --all`) plus the working tree, so it also lists sessions whose
handoff is not merged yet. If it looks stale, or if git reports a merge
conflict on it, do not resolve anything by hand: rerun the script and commit
the result.

    bash .claude/scripts/relevio-index.sh              # script install
    bash "$CLAUDE_PLUGIN_ROOT/scripts/relevio-index.sh"  # plugin install

**Active lanes** is the team board: one row per branch that still has open
work. **Catalog** is the full history: every session ever closed, whichever
branch it happened on.

How to find something:
1. Scan the tables below (dates, branches, areas, topics, summaries).
2. Full-text search the handoffs: `grep -ri "<topic>" docs/handoff/`.
3. Which sessions touched a file or directory, and who has open work on it:
   `bash .claude/scripts/relevio-trace.sh <path>`.
4. Want the code trail? `git log <first>^..<last>` with the row's commit range
   (the `^` is needed: `a..b` would drop the session's own first commit).
5. Need the full reasoning? Reopen the matching conversation from your session
   list: it has everything the handoff summarized.

A handoff survives only while git can still reach it. Push your branch and get
it merged: a handoff committed on a branch that is deleted before merging
disappears from this index along with the branch.
